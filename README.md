# 🚰 Plomberie Metz

A modern, responsive plumbing business website built with **HTML**, **CSS**, and **JavaScript**.

This website was created to promote professional plumbing services in Metz, France, with a clean design, fast loading times, and a mobile-friendly user experience.

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Modern hero section with background image
- Professional service presentation
- Contact section
- Click-to-call button
- Smooth navigation
- SEO-friendly structure
- Lightweight and fast loading

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
